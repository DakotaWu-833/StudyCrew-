# StudyCrew AI：真实模型验证记录

本记录对应 `advance` 的 Qwen 接入、混合检索和人工审批扩展。模型实测于 2026-10-13 在本地完成，原始合成数据报告见 [ai-synthetic-smoke.json](evidence/ai-synthetic-smoke.json)。这些数字描述一次小样本服务层验证，不能当作学校用户准确率、生产并发能力或公网部署证明。

## 环境与模型

- Windows、Python 3.12；NVIDIA GeForce RTX 4080 Laptop GPU，12,282 MiB 显存，驱动 566.07。
- Ollama 0.40.3；`ollama ps` 实际显示两个模型均为 100% GPU offload。
- 聊天/工具调用：`qwen3.5:9b-q4_K_M`，权重 digest `56671c2ab9385f9cfcb404638e32cd62d88e3501d44822208363c010179a3c90`。
- 向量：`qwen3-embedding:0.6b`，digest `ac6da0dfba84a81fdbfbaf330198c33cd77c4cdfc53e8bc50eb581914a15621d`；1,024 维。
- 聊天上下文 8,192 tokens、输出上限 1,200、thinking 关闭；单次模型预算 20 秒，RAG/Agent 整体预算最高 24 秒。推理服务仅绑定本机。

使用主流开放模型的目的，是在现有 GPU 上完成可复现的本地推理和中英文项目资料检索。模型文件和运行日志位于忽略目录 `var/ai/`，不随源码或部署 ZIP 上传。

## 固定合成数据集的结果

脚本创建临时 SQLite、媒体目录、随机密码的合成账户及虚构项目，使用 10 份英文 TXT、1 条会议纪要和任务记录。检索集含 7 个英文问题和 5 个中文跨语言问题，每题指定一个预期来源。没有使用真实学生资料。

| 项目 | 结果 | 范围 |
|---|---:|---|
| BM25 Recall@5 / MRR@5 | 7/12；0.5833 / 0.5833 | 中文问题与英文材料缺少词面重叠 |
| Hybrid Recall@5 / MRR@5 | 12/12；1.0 / 1.0 | 同一固定合成检索集 |
| Hybrid 检索中位数 / 样本 P95 | 0.256 / 0.271 秒 | 12 次、模型已预热、向量缓存已建 |
| 首次建立 11 条向量缓存并检索 | 0.679 秒 | 空数据库缓存，模型已预热 |
| 引用问答 | 6/6 返回带有效标签的回答，预设事实词出现 | 标签/关键词检查不等于事实蕴含验证 |
| 问答中位数 / 样本 P95 | 2.223 / 4.236 秒 | 6 次顺序服务层调用 |
| Agent 提案 | 11.611 秒；完成三种工具调用，产生 1 张草稿 | 查资料、读任务、调用 `propose_tasks` |
| 中文阻塞任务查询 | 2.585 秒；完成并引用当前任务 | 真实 `list_project_tasks` 调用 |
| 明确审批与同内容重试 | 首次创建 1 项、重试返回同一任务 | 合成数据中显式模拟用户审批 |

无权限账户被拒绝，另一个项目的秘密标记没有进入检索来源。询问不存在的私人电话时，模型说明材料没有提供；原始报告保留完整回答，人工评阅仍需检查其额外推断。嵌入指令案例中，模型曾复述假密码；后端模式检查拦截最终输出，报告显示 `unverified_answer` 且 `answer=null`。这是有限凭据模式检查，不代表完整 DLP 或所有提示注入场景均安全。

实测期间也发现模型可能漏掉引用标签，或只在正文中写任务建议。最终提示要求提案调用工具；引用缺失时仅允许在原轮数和时间预算内纠正一次，纠正轮禁止额外工具。仍不合格的回答会被扣留，系统没有把模型输出直接当作可信业务指令。

## 自动化验证与部署边界

后端全量 **1,037 项测试通过，分支覆盖率 91.6%**。最终前端全量 **265 项测试通过**，类型检查、生产构建和产物一致性检查通过。数据库迁移差异检查、Django 配置检查和 OpenAPI 生成/校验通过。安装脚本已实际复用已下载模型并完成合成预热。

MFA/CSRF、当前成员权限、文件版本/完整性/扫描状态、审批签名 600 秒有效期、源变化拒绝、事务回滚和同内容回执等有定向回归。纪要与会议写入统一了锁顺序；当前数据库测试为 SQLite，尚未取得真实 PostgreSQL 并发或生产角色验收证据。浏览器自动验收工具启动失败，页面行为证据来自 React 测试，不能标为真实浏览器视觉验收。

目前用户选择先准备部署包，尚无公网服务器。Docker GPU、实际 PostgreSQL、域名/TLS、SMTP、负载和备份恢复仍需在目标主机验收。源码配置和本地 GPU 结果不等于已经上线。
