# StudyCrew 本地上线功能验收

`advance` 已完成此次上线前 P0 和 P1 范围，并继续完成校园招募、私有文件版本、作业 CSV 交换和七项本地增强，基于创建分支时的 `develop`。代码、数据库迁移、界面、验证和部署配置都留在本地；这次没有提交、推送或发布公网服务。本文更新日期为 2026 年 10 月 2 日；中英文界面切换不在本轮范围，新增功能详见[本地扩展验收](advance-local-expansion.md)。

## 本地验收结果

- 本轮后端全量 **836 项通过**，耗时 78.304 秒；启用分支统计的综合覆盖率 **91.8%**（语句 **93.6%**、分支 **83.9%**），通过 90% 综合覆盖率检查门槛，包括原有功能和七项增强。
- 本轮前端 **36 个测试文件、213 项通过**；类型检查和生产构建通过，构建额外检查页面分块不会重新加载应用入口。
- 本轮迁移一致性检查无变动，API 文档生成通过严格无警告验证。
- 本轮真实浏览器通过文件预览/差异/恢复、周期任务/工时、事实工作量、推荐、双账户聊天与撤下、离线刷新/编辑/逐字段冲突和注销清理。聊天、工作量、任务工具、离线任务、文件五个页面在 390 像素宽度下无整页溢出，浏览器无意外错误。
- 本轮隔离 SQLite 恢复比对 **98 张表、969 条记录、21 个清单文件**，结构和每张表全部记录一致；聊天/撤下、周期任务、更正工时、文件内容、离线回执及个人导出七项运行检查全部通过。文件级恢复与比对 **0.141 秒**，不代表灾难恢复 RTO。证据指向 `var/advance-enhancements-*.log`、`var/advance-qa/enhancements-ui-result.json` 和 `var/advance-enhancements-restore/`。

以下浏览器、并发、恢复及备份结果是此前 P0/P1 验收记录；招募/文件/CSV 的上一轮额外验收另见[本地扩展验收](advance-local-expansion.md)。它们不会替代本轮新增模块的真实浏览器与恢复结果。

- Django 本地配置检查、迁移一致性检查和规范 API 文档生成通过。新增生产上传检查要求真实可用的 ClamAV；本地验证了缺失扫描器会拒绝通过，完整生产检查仍待真实主机完成，未连接生产数据库或邮件服务。
- 实际浏览器经过密码和文件邮件验证码登录；发布公告、回复、草稿刷新恢复、跨模块搜索、今日筛选和周/月切换成功。390 像素宽度下检查五个主要页面，没有整页横向溢出；主动断网后显示通用提示，未读取缓存的私有项目页面。最终浏览器验收没有意外控制台错误。
- 隔离本地演示中，**5 个并发客户端、30 次请求**全部成功：25 次登录后读取、5 次带防伪验证的任务创建。中位响应 213.88 毫秒，95 分位 331.94 毫秒。这是小型 SQLite 演练，不代表公网 PostgreSQL 容量。
- 真实 SQLite 恢复比对 **80 张表、572 条记录**，数据库结构、每张表全部记录指纹和 4 个清单文件一致。文件恢复和比对耗时 0.125 秒，不能当作整体灾难恢复时间。恢复副本随后完成密码/邮件验证码登录、创建任务、课程读取和外部成员访问拒绝。
- 自动备份实际执行并通过完整校验；worker 和备份 freshness 检查通过。离机传送的 5 项测试使用明确的工具替身，验证失败处理和不覆盖旧备份，没有实际上传。

本地证据保存在忽略目录 `var/advance-qa/`、`var/advance-restore-delivery/`，完整测试和覆盖率日志在 `var/advance-tests-final.log`、`var/advance-coverage-final.txt`。这些目录包含隔离演示数据，不应作为学生数据或生产凭据上传。

## 运行本地版本

已有依赖和构建文件时，在项目根目录用 PowerShell 7 执行：

```powershell
.\scripts\Start-Advance.ps1 -Port 8003
.\scripts\Start-Advance.ps1 -Demo -Port 8002
```

正常本地数据入口为 `http://127.0.0.1:8003/app/`，使用原有本地账号，验证码写入 `var/emails/`；隔离演示入口为 `http://127.0.0.1:8002/app/`，验证码写入 `var/advance-preview-emails/`。8000/8001 的旧预览可能尚未更新。两种模式按要使用的数据选择，演示数据库、媒体和邮件目录均独立；已有密码保留，启动器停止时只清理它启动的进程。正常本地数据库已应用本轮新增迁移。

详细运行和发布流程见 [运行说明](launch-operations.md)，离机加密配置见 [离机备份说明](../deployment/scripts/backup-offhost.md)。

## 公网开放前仍需部署验收

真实域名与 HTTPS、受限 PostgreSQL 实例、验证过的邮件发件人及回调密钥、云端备份凭据与离线解密密钥均需要部署环境提供。配置模板已准备好，但这些外部服务没有在本地假装接通。

首次开放学生试用前，应在真实环境完成邮件收发/退信回调、数据库角色权限、反向代理日志脱敏、独立 worker 和定时服务、从云端取回并解密恢复，以及代表性用户规模的性能演练。容量、存储、预算和远端保留锁要按实际试用人数设置；此处没有承诺生产 SLA。

上线迁移后需重新应用 PostgreSQL 清理权限并以真实角色验证，新增聊天心跳和离线同步回执的删除授权目前只在脚本与本地配置层面检查，未在真实 PostgreSQL 执行。worker 负责周期任务生成、7 天同步回执清理和 5 分钟旧心跳清理。

校园招募、受限类型的私有文件托管、作业 CSV 的本地交换及七项增强现已实现。实时 LMS/OAuth 深度集成、AI、收费和学校机构 SSO/LTI 尚未实现；CSV 交换不代表已接通学校系统。软件仍使用学校原有提交渠道。
