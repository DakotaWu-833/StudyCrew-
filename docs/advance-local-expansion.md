# StudyCrew 本地扩展与验收

本轮继续开发 `advance`，在已有 P0/P1、校园招募、私有文件和作业 CSV 交换上，补充七项本地增强。分支仍基于创建时的 `develop`，所有变更留在本地，未提交、推送或上线。本文更新日期为 2026 年 10 月 2 日；中英文界面切换不在本轮范围。

## 可以使用的功能

| 功能 | 入口 | 行为和权限 |
|---|---|---|
| 校园招募 | 工作区 Find a team | 负责人明确同意后发布学校、课程、技能、语言和协作方式；关键词筛选、收藏、申请与撤回、批准/拒绝、关闭/到期、举报和管理员处理。学校信息为自述。公开卡片不泄露私有项目编号、任务或邮箱，批准后才加入真实项目。 |
| 私有文件 | 项目 Files | 上传、文件夹、标签、搜索、置顶、授权下载、版本历史与旧版本下载、删除和保留期清理。当前成员可读；作者或管理员可修改，只有管理员可置顶；项目归档后只读，离组即收回下载权限。 |
| 作业文件交换 | 项目 Assignment import | 下载示例、上传 CSV、逐行预览、明确确认后原子创建任务和正式截止日期、来源编号去重、重复批次幂等、历史及当前任务导出。仅负责人/协调员可导入；成员可读取与导出。 |

私有文件默认上限为每个文件 10 MiB、每项目 250 MiB、每天每人 100 MiB / 30 次上传，每项目最多保留 2,000 个版本，每个文档最多 50 个版本。版本和删除后尚在保留期内的文件都计入容量。支持 PDF、UTF-8 TXT/CSV、PNG/JPEG、受限 DOCX/XLSX/PPTX 和受限 ZIP；ZIP 内仅允许普通 PDF、文本、CSV 和图片，不支持任意代码压缩包。Office 宏、嵌入对象及外部关系、压缩炸弹、路径穿越、执行文件均会被拒绝。

本地未安装恶意软件扫描器时，界面明确标注未扫描。生产环境必须启用 ClamAV，未配置扫描器、扫描失败或超时都会拒绝上传。格式检查不代表文件完全无害，也没有承诺完整内容重构。设计参考 [OWASP 文件上传建议](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)。

作业 CSV 每次最多 256 KiB / 100 行，预览 30 分钟到期。支持通用格式，以及界面明确列出的 Canvas/Moodle 样例字段；学校其他格式需要先转换。夏令时重复/不存在的本地时间会被拒绝，建议带明确 UTC 偏移。使用稳定的来源编号可防止后续文件覆盖既有任务；没有编号时按内容生成编号，内容改变可能产生另一项任务。导入失败整批回退。CSV 导出处理公式注入。此功能不登录学校、不自动同步课程或自动提交作业。

账户关闭会退下招募、取消未决申请、移除草稿预览、停止本人创建文档的下载；共享审核和导入历史保留去标识的作者记录。个人数据下载包括本人上传到他人文档中的版本；离组后的文件和导入内容会被隐藏。

## 本轮七项本地增强

| 功能 | 入口 | 行为和边界 |
|---|---|---|
| 文件预览与版本比较 | 项目 Files 的 Preview / Versions | 当前和历史版本可预览 PDF、PNG/JPEG、UTF-8 TXT/CSV；PDF 在本地画布呈现。版本差异仅支持 UTF-8 TXT/CSV，不比较 PDF 或 Office 二进制内容。每次预览、比较仍检查当前成员权限及文件完整性。 |
| 回收站恢复 | 项目 Files 的 Recycle bin | 删除立即停止下载；保留期内作者或项目管理员可恢复，满 30 天不能恢复。项目归档时只读；作者关闭账户而移除的文件不能恢复。恢复会检查版本完整性及当前修订号，保留文件继续计入容量。 |
| 周期任务 | 任务详情的 Recurring tasks | 按周或按月、指定 IANA 时区和本地截止时间生成独立任务；提前 0–30 天创建，结束日期不超过十年、最多 520 次。可停止未来生成，已生成任务保留。只复制仍为有效项目成员的任务指派人员。 |
| 组队推荐 | Find a team 的推荐入口 | 根据本人课程、技能、沟通语言和协作方式给出逐项匹配理由；已加入、已申请、过期或不可见卡片不会作为新推荐。课程优先，再看技能、语言和协作方式，同等匹配按发布时间排序；不推断学生能力或团队质量分数。 |
| 实际工时与工作量 | 任务 Time spent、项目 Workload | 开始/停止计时、手动补记、本人更正或撤销记录。展示已完成计时、未完成任务、预估工时和截止时间分布；多人任务的预估工时均分，未分配任务单列。运行中的计时不进入总计，单条记录上限 24 小时，私人备注不向队友公开。 |
| 项目聊天 | 项目 Chat | 当前成员发送纯文本消息、加载较早消息、作者或管理员撤下消息、查看最近在线成员；归档项目只读。前台每 2 秒、后台每 10 秒轮询，35 秒内的心跳显示在线；使用 HTTP 轮询，没有 WebSocket。 |
| 离线任务编辑与同步 | 任务 Keep this task offline、工作区 Offline tasks | 在线时主动启用并选择任务，本浏览器最多 200 份任务副本、50 项待同步编辑，副本和编辑 24 小时到期。只支持任务标题、描述、优先级、截止时间、状态和阻塞说明；恢复网络后检查身份、成员权限、当前版本及原有完成前置条件再同步。冲突逐字段选择，未选择的字段保留服务器值。 |

文本预览最多展示前 512 KiB；版本差异每版最多 256 KiB、2,000 行且单行最多 5,000 字符，输出也有大小上限并提示截断。Office、ZIP 等其他允许上传的格式仍通过授权下载查看，不会作为内嵌网页执行。

周期任务保存创建排期时的标题、描述、优先级、验收要求、标签、预估工时和检查项文字快照；后续修改源任务不会悄悄改变快照。新任务重置检查项完成、审核、依赖、父任务和正式作业截止日期。月末日期落在当月最后一天；夏令时重复时段采用第一次，不存在的时段向后移动。后台 worker 生成到期任务；生成过程有防重复记录，关闭账户、离组或归档会停止后续生成。

推荐只评估最新的最多 200 张符合条件的卡片，每页 20 条，界面披露候选窗口和资料缺项；它不会读取其他学生的私人资料。课程和学校信息仍为本人填写。

离线数据存在本机 IndexedDB，和浏览器对公共代码/通用外壳的缓存分开。API 响应、文件、聊天、全部项目页面不会被 Service Worker 缓存。注销、会话失效或确认切换账户会清理本机副本；离线时尚无法获知的远端权限变化，在重连时重新检查。同步发送保存者的 `expected_user_id`，避免切换账户后的旧请求应用到新账户。传输失败保留同一重试编号，旧请求的迟到结果不会删除后续的新编辑；权限撤销或任务消失会删除相应副本。离线复制由用户主动选择，其他设备已有的副本需在其重连后检查，不能远程立即擦除。

## 上一轮已验证的结果

- 后端全量 724 项通过，启用分支统计的综合覆盖率 91.5%；新增功能及账户边界的集中回归共 113 项通过。
- 前端 27 个文件、149 项通过；类型检查、生产构建、单应用入口检查通过。
- Django 配置和迁移一致性检查通过；规范 API 文档生成验证无警告。
- 浏览器经过密码和文件邮件验证码登录，发布招募、申请、批准及实际项目访问；批准前项目访问被拒绝。
- 浏览器完成私有文件上传、认证下载内容比对、第二版上传、旧版保留；普通成员可读，但不能修改他人的文件或置顶。
- 浏览器完成作业 CSV 预览与确认，创建真实任务；再次预览识别重复项，普通成员没有导入入口。
- 三个新页面在 390 像素宽度下无整页横向溢出，验收没有意外浏览器错误。
- 新数据库和媒体的隔离恢复比对了 91 张表、712 条记录及 4 个清单文件，结构与全部记录一致。恢复副本中，负责人和学生都成功下载并核对第二版私有文件，导入历史及各自权限一致。文件恢复比对耗时 0.109 秒，不是整体灾难恢复时间。

日志与演示证据位于忽略目录：`var/advance-expansion-backend-final.log`、`var/advance-expansion-coverage-final.txt`、`var/advance-qa/expansion-ui-result.json`、`var/advance-expansion-restore/`。这些不是生产学生数据，也不应提交演示账号凭据或会话。

## 本地使用和运营

正常本地数据运行在 `http://127.0.0.1:8003/app/`，可用原有本地账号登录；隔离演示和测试运行在 `http://127.0.0.1:8002/app/`。原来的 8000/8001 端口预览仍可能显示旧的后端版本。启动更新版本使用 PowerShell 7，按要使用的数据选择命令：

```powershell
.\scripts\Start-Advance.ps1 -Port 8003
.\scripts\Start-Advance.ps1 -Demo -Port 8002
```

保留当前启动窗口时无需再次运行同端口命令。正常账号验证码保存在 `var/emails/`；演示邮箱验证码保存在 `var/advance-preview-emails/`。

上一轮正常本地数据库已应用四个新增迁移。在修改正常数据库前，数据库和媒体完整备份至忽略目录 `var/advance-normal-before-expansion/`；备份包含四个清单文件及媒体。迁移未重置账号或项目。本轮迁移前另做了包含数据库和媒体的完整备份 `var/advance-normal-before-enhancements-full/`。本轮文件恢复限制、周期任务/工时、聊天和离线同步回执四个迁移已应用到正常本地数据库，8003 启动检查没有待应用变动。

文件删除后立即停止下载，保留 30 天后可执行清理。先查看待清理数量，再明确应用：

```powershell
.\.venv\Scripts\python.exe manage.py purge_private_files
.\.venv\Scripts\python.exe manage.py purge_private_files --apply
```

`--orphans` 额外处理超过 48 小时、无数据库引用且路径格式严格匹配的崩溃残留文件。学习导入预览由运行中的 worker 清理，也可运行 `cleanup_learning_previews`。Linux 文件清理 service/timer 模板位于 `deployment/systemd/studycrew-private-file-cleanup.*`，每日 04:00 UTC 执行，只清理已移除且满 30 天的文件；尚未在真实 Linux 上启用。更新后的 PostgreSQL 权限脚本允许必要清理，仍保护既有审核日志。

worker 每轮生成到期周期任务，清理满 7 天的离线同步回执和超过 5 分钟的聊天在线心跳。35 秒的在线展示期限与 5 分钟的心跳记录清理期限用途不同。上线迁移后须重新应用并验证 PostgreSQL 清理权限，新增允许删除 `project_chat_chatpresence` 和 `offline_sync_tasksyncreceipt`；这两项权限只准备了脚本与配置检查，尚未在真实 PostgreSQL 角色下执行验证。审核日志的不可修改保护保留。

生产接入还须安装并更新 ClamAV 病毒库，应用 Nginx 上传路径限制与数据库角色权限，验证实际扫描、下载、清理和云端恢复。这里未连接生产 PostgreSQL、学校身份系统或云端服务。实时 LMS/OAuth、AI、收费、机构 SSO/LTI 仍是后续功能。
